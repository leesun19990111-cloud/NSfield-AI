- 본문/UI: `Pretendard` (한글 우선) + `Inter` (라틴)

- 스케일: `text-xs 12 / sm 14 / base 15 / lg 18 / xl 22 / 2xl 28 / 3xl 36`

### 컴포넌트 기반

- **shadcn/ui** (Radix primitives) — 다크 테마 커스터마이즈
- 아이콘: `lucide-react`
- 차트(관리자): `recharts`
- 폼: `react-hook-form` + `zod`
- 토스트/알림: `sonner`

## 1. 사용자 페이지

### 1.1 라우트 맵

| 경로 | 화면 | 인증 | 렌더링 |
|---|---|---|---|
| `/` | 랜딩 | 공개 | Server (정적) |
| `/models` | 모델 카탈로그 | 공개 | Server |
| `/models/[id]` | 모델 상세 | 공개 | Server |
| `/auth/login` | 로그인 | 비로그인 | Client |
| `/auth/signup` | 회원가입 | 비로그인 | Client |
| `/auth/callback` | OAuth 콜백 | — | Route Handler |
| `/generate/[modelId]` | 생성 스튜디오 | USER | Server+Client |
| `/wallet` | 지갑 (잔액·거래내역) | USER | Server |
| `/wallet/topup` | 충전 요청 | USER | Server+Client |
| `/library` | 라이브러리 (생성 결과) | USER | Server |
| `/library/[genId]` | 생성 결과 상세 | USER | Server+Realtime |
| `/account` | 계정 설정 | USER | Server+Client |

### 1.2 랜딩 `/`

목적: "구독제에 지친 사람에게 쓴 만큼만"이라는 가치 전달 + 로그인 유도.

```
┌───────────────────────────────────────────────────────────┐
│                                                            │
│              NS Field                                      │
│              Not Script.                                   │
│                                                            │
│        구독 없이, 쓴 만큼만.                                 │
│        7개 최신 AI 모델로 이미지와 영상을 만들고             │
│        사용한 금액만 정확히 차감합니다.                       │
│                                                            │
│        [모델 둘러보기]   [시작하기 →]                        │
│                                                            │
├───────────────────────────────────────────────────────────┤
│   왜 NS Field?                                             │
│   ┌─────────┐ ┌─────────┐ ┌─────────┐                     │
│   │ 월정액 X │ │ 7개 모델 │ │ 투명 과금│                     │
│   │ 충전식   │ │ 한 곳에  │ │ 실시간   │                     │
│   └─────────┘ └─────────┘ └─────────┘                     │
├───────────────────────────────────────────────────────────┤
│   지원 모델                                                 │
│   이미지: GPT-Image-2.0 · Seedream 4.5 · Nanobanana 2.0/Pro │
│   영상:   Seedance 2.0 · Kling · Veo3                       │
│   [전체 가격 보기]                                          │
└───────────────────────────────────────────────────────────┘
```

- 로그인 상태면 [시작하기] → `/models`, 비로그인이면 → `/auth/login`.
- 가격 미끼: 대표 모델 3개의 최저 단가를 USD로 노출(예: "이미지 1장 $0.04부터").

### 1.5 생성 스튜디오 `/generate/[modelId]` ★ 핵심 화면

목적: 프롬프트·참조이미지·옵션 입력 → 견적 확인 → 생성 → 결과. 이미지/영상 공용, `kind`에 따라 옵션 패널만 분기.

```
┌───────────────────────────────────────────────────────────┐
│  ← 모델   Veo3 (영상)                          💰 ₩30,000  │
├──────────────────────────────────┬────────────────────────┤
│  입력 패널 (좌, 40%)               │  결과 패널 (우, 60%)    │
│                                   │                        │
│  프롬프트                          │   ┌──────────────────┐ │
│  ┌─────────────────────────────┐  │   │                  │ │
│  │ (멀티라인 textarea, 2000자)  │  │   │   결과 미리보기    │ │
│  │                             │  │   │   (생성 전: 빈 상태│ │
│  └─────────────────────────────┘  │   │    안내 일러스트)  │ │
│  0/2000                           │   │                  │ │
│                                   │   └──────────────────┘ │
│  참조 이미지 (선택)                 │                        │
│  ┌──────────┐                     │   생성이 시작되면 여기에 │
│  │ + 드래그  │  (≤10MB,jpg/png)    │   진행 상황이 표시됩니다 │
│  └──────────┘                     │                        │
│                                   │                        │
│  ── 영상 옵션 ──                   │                        │
│  길이:  ○3 ●5 ○10 ⊘15 ⊘30 ⊘1분   │   (⊘ = 이 모델 미지원) │
│  화면비: [16:9 ▾]                  │                        │
│  해상도: [720p ▾]                  │                        │
│                                   │                        │
│  ─────────────────────────────    │                        │
│  예상 차감                         │                        │
│   $0.50  ≈ ₩690                   │                        │
│   (현재 환율 1USD=1,380₩,마진 포함)│                        │
│  생성 후 잔액: ₩29,310             │                        │
│                                   │                        │
│  [✨ 생성하기]                     │                        │
│  └ 잔액 부족 시: "₩X 부족 [충전]"  │                        │
└──────────────────────────────────┴────────────────────────┘
```

상태별 결과 패널:
- **생성 전**: 빈 상태 안내
- **이미지(동기) 생성 중**: 스켈레톤 + 스피너, 버튼 로딩 (보통 5~30초)
- **영상(비동기) 등록됨**: "작업이 등록되었습니다. 완료되면 알려드릴게요" + 진행 바(폴링 단계 표시) → Realtime 구독으로 자동 갱신, 사용자는 페이지 떠나도 됨(라이브러리에서 확인)
- **성공**: 결과 미리보기 + [다운로드] [라이브러리에서 보기] [새로 만들기]
- **실패**: 실패 사유 + "전액 환불되었습니다 (₩690)" + [다시 시도]

세부 동작:
- 길이 옵션은 6개 항상 표시, 모델 미지원은 `⊘` disabled + 툴팁("Veo3는 최대 10초 지원").
- 옵션 바뀔 때마다 견적 실시간 재계산(클라이언트 — 가격 규칙은 서버에서 받아온 모델 메타로 계산, 차감은 서버가 재검증).
- [생성하기] → 견적 확정 모달(금액·잔액 재확인) → Server Action 호출.

## 3. 공통 UX 규칙

| 규칙 | 적용 |
|---|---|
| 금액 표기 | 차감/원가=USD 주표기, 잔액=KRW 주표기, 항상 반대 통화 병기 |
| 환율 명시 | 견적·차감·잔액 화면에 항상 "1USD=N₩" + 갱신 시각 |
| 로딩 | 이미지 동기=스켈레톤, 영상 비동기=진행 바 + 페이지 이탈 허용 |
| 실시간 | 생성 상태는 Supabase Realtime 구독, 폴링 코드 클라이언트 없음 |
| 에러 | 사용자向 한국어 메시지 + 환불 발생 시 금액 명시 |
| 빈 상태 | 모든 목록/그리드에 일러스트 + 다음 행동 CTA |
| 확인 모달 | 금전 차감·승인·거절·강제환불·조정에 필수 |
| 접근성 | 키보드 포커스, ARIA, 명도 대비 WCAG AA(다크 기준) |
| 반응형 | 데스크톱 우선; 모바일은 좌우 2단→세로 1단, 관리자 테이블=카드형 전환 |
